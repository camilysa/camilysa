* **[Sistema de Análise de Risco de Crédito (Em desenvolvimento)](https://github.com/camilysa/credit-risk-analytics)**
  * *Tecnologias:* Python, PostgreSQL, Pandas, Power BI, Scikit-Learn.
  * *Descrição:* Projeto end-to-end simulando o setor financeiro: ingestão de dados em PostgreSQL, tratamento em SQL, modelo preditivo de inadimplência em Python e dashboard no Power BI.

  * *Descrição:* Análise exploratória cobrindo as 22 edições da era dos pontos corridos para mapear métricas, padrões estatísticos e anomalias históricas (como o Flamengo de 2019 e o São Paulo de 2007).

  * *Tecnologias:* Linguagem C, GCC, Batch Scripting, Manipulação de Arquivos.
  * *Descrição:* Jogo interativo de suspense para terminal desenvolvido em C, aplicando arquitetura modular, controle de estados por escolhas e persistência de dados em arquivos.
